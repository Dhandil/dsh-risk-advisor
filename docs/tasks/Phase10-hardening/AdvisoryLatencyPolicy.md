# Advisory Latency Policy — Phase 10 R2

This is bounded evidence and policy guidance. It does not change production
timeouts, queue bounds, concurrency, polling, approval configuration, or
product semantics. The authoritative numeric source is
`evidence/r5-phase10-measurements.json` generated by the corrected Phase 10
benchmark.

The benchmark uses the pinned local Harness and deterministic local adapters;
no external provider, network, registry, or Git remote was exercised.

## Evidence classes

- `REAL_PINNED_RUNTIME`: real pinned Harness ApprovalService fixture and local
  Risk Advisor path, with one native answerer per iteration.
- `REAL_PRODUCT_LOCAL`: executable Risk Advisor code with disposable files,
  bounded schedulers, local deterministic LLM/subagent adapters, actual A2/A3/A4
  merges, and the real presentation/query seam.
- `STRUCTURAL_LOCAL_REVIEWER`: bounded local reviewer adapter, not provider
  latency.
- `STRUCTURAL_PROMPT_INJECTION_HARDENING`: runtime canary and hostile-candidate
  denial proof over bounded serialized surfaces.
- `NOT_VALIDATED_EXTERNAL_PROVIDER`: production provider latency was not run.

All distributions use nearest-rank quantiles and report milliseconds. Full
sample arrays remain in the evidence artifact.

## Policy boundaries

`T_sync` remains observation-only. The unchanged Fast and Deep scheduler
timeout is 5000 ms; both use `maxConcurrent=2` and `maxPending=8`. The client
1000 ms polling ceiling and 3000 ms NOT_FOUND grace are unchanged. Local
measurements do not define an SLA, lower a timeout, or alter Native Approval.

External provider latency is `NOT_VALIDATED_EXTERNAL_PROVIDER` / `NOT_RUN`.
No provider, external network, registry, or Git-remote call was made.

## Privacy and authority

The corrected artifact records 16 canary surfaces with zero canary, raw-field,
private-path, and captured-logger matches. Focused proof also sends a canary
through the actual Evidence target seed, collector, sanitized snapshot, A3,
Deep payload, and Browser V4 projection; raw seed state is consumed. Direct
hostile Fast and Deep merge proofs preserve deterministic/evidence risk floors,
keep hypotheses as hypotheses, and keep alternatives
`MODEL_SUGGESTED / UNVERIFIED`.

The published UI remains advisory-only. Evidence may be stale at execution
time; no measurement above is an execution-time verified claim.
